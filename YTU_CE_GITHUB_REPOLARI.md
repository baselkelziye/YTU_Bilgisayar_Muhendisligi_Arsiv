# YTÜ Bilgisayar Mühendisliği Öğrencilerine Ait GitHub Repoları

Bu liste, GitHub'da açık olan, Yıldız Teknik Üniversitesi Bilgisayar Mühendisliği öğrencilerine/mezunlarına ait ve henüz bu arşive eklenmemiş ödev, proje ve ders notu repolarını içerir. Arşive içerik eklemek veya repo sahipleriyle katkı için iletişime geçmek amacıyla hazırlanmıştır.

**Yöntem (2026-10-21):** GitHub araması `YTU`, `ytu-ce`, `Yildiz Technical University`, `Yıldız Teknik`, `yildiz` ve BLM ders kodlarıyla (BLM1011, BLM2512, BLM3021, BLM3520 vb.) yapıldı. Sonuçlar elle ayıklandı:

- Açıklamasında YTÜ Bilgisayar Mühendisliği, `ytu-ce`/`ytu_ce` ya da BLM ders kodu geçen, veya klasörlerinde YTÜ CE ders adları bulunan repolar alındı.
- Başka YTU'lar (Yantai University, Yangon Technological University), başka bölümler (Mekatronik, Matematik, Fizik, Elektronik vb.), kulüp/yemekhane botları, boş repolar ve forklar çıkarıldı.
- Bu arşivde zaten bağlantısı olan repolar ve mevcut katkıda bulunanlar listeye alınmadı.
- Doğrulama açıklama, klasör yapısı ve profil bilgisine dayanır. Repo sahibinin gerçekten YTÜ CE öğrencisi olduğu kesin değildir; eklemeden önce içerik kontrol edilmeli ve sahibinden izin alınmalıdır.

Toplam: **185 repo**, **117 kişi/organizasyon**.
