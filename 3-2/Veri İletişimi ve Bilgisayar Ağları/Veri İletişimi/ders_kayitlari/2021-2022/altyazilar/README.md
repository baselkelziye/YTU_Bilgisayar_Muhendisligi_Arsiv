# Veri İletişimi Ders Kayıtları Altyazıları

Bu klasör, 2021-2022 eğitim öğretim yılı Güz dönemindeki Veri İletişimi ve Bilgisayar Ağları (BLM3051 - 3. şube) ders kayıtlarının altyazılarını içerir.

* **Dersi Veren Akademisyenler:** Dr. Ziya Cihan Tayşi (vize öncesi, `ders_1` - `ders_12`), Dr. Furkan Çakmak (vize sonrası, `ders_14` - `ders_19`)
