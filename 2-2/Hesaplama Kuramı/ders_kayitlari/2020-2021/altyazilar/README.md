# Hesaplama Kuramı Ders Kayıtları Altyazıları

Bu klasör, 2020-2021 eğitim öğretim yılı Bahar dönemindeki Hesaplama Kuramı (BLM2502 - 2. şube) ders kayıtlarının altyazılarını içerir.

* **Dersi Veren Akademisyen:** Dr. Oğuz Altun

Bu şubede ders **İngilizce** anlatılmıştır; altyazılar İngilizcedir, araya giren Türkçe konuşmalar Türkçe yazılmıştır. Çalışma özetleri Türkçedir.

Dersler 9 Mart 2021 Salı günü başlamıştır. Ders haftada bir kez (Salı) yapılmıştır. Dosya adlarındaki `ders_x.srt` ifadesinde `x`, ilgili kaydın kayıt arşivindeki ders sıra numarasını gösterir.
