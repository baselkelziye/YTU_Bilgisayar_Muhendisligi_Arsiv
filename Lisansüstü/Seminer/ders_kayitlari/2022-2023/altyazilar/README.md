# Seminer Ders Kayıtları Altyazıları

Bu klasör, 2022-2023 eğitim öğretim yılı Bahar dönemindeki Seminer (BLM6001 - 1. şube) ders kayıtlarının altyazılarını içerir.

Kayıt arşivindeki ilk ders kaydı 28 Şubat 2023 Salı gününe aittir. Dosya adlarındaki `ders_x.srt` ifadesinde `x`, ders haftasını değil, ilgili kaydın kayıt arşivindeki ders sıra numarasını gösterir. Tarihler YTÜ Video Ambarı kayıt tablosundan alınmıştır. Altyazılardaki öğrenci adları `[öğrenci]` ile maskelenmiştir.
