# Web Madenciliği Ders Kayıtları Altyazıları

Bu klasör, 2020-2021 Güz eğitim öğretim yılındaki Web Madenciliği ders kayıtlarının altyazılarını içerir.

* **Dersi Veren Akademisyen:** Prof. Dr. Mehmet Sıddık Aktaş

Dersler 6 Ekim 2020 Salı günü başlamıştır. Ders haftada bir gün (Salı) online olarak yapılmıştır. Dosya adlarındaki `ders_x.srt` ifadesinde `x`, ilgili kaydın kayıt arşivindeki ders sıra numarasını gösterir. Tarihler YTÜ Video Ambarı kayıt tablosundan alınmıştır. Altyazılardaki öğrenci adları `[öğrenci]` ile maskelenmiştir.
