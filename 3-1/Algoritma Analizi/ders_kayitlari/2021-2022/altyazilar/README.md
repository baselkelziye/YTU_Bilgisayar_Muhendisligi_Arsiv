# Algoritma Analizi Ders Kayıtları Altyazıları

Bu klasör, 2021-2022 eğitim öğretim yılı Güz dönemindeki Algoritma Analizi (BLM3021 - 3. şube) ders kayıtlarının altyazılarını içerir.

Kayıt arşivindeki ilk ders kaydı 20 Ekim 2021 Çarşamba gününe aittir. Altyazılardaki öğrenci adları `[öğrenci]` ile maskelenmiştir.
