# Prime Number Analysis

This program analyzes a given integer to determine whether it is a prime number.

## Description
The program first checks if the given integer N is prime. If N is not prime, it calculates all of its prime factors (including repeated factors) and stores them in an array in the DATA segment. Using these factors, the program then determines and stores the largest prime factor.

## Features
- Checks whether a given integer is prime
- Computes all prime factors (with repetition) if the number is not prime
- Stores prime factors in the DATA segment
- Determines and stores the largest prime factor
